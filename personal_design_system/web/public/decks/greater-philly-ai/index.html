Real tokens

The comment does more work than the hex.

colors:
  ink:     "#0A0A0A"   # headlines, body text. the voice of the document.

Read the comment out loud. The hex says what the color is. The comment says when to stop.

Its recommendation

Update the system, not the site.

Close to verbatim. It did not just find the mismatch, it took a position on which side was wrong, and it argued the brand is materially cooler and lighter than the documentation claimed. It found the drift.

It could not choose.

The room will trust everything else more for this. The audit ended with three options for the stray colors: park them, deploy them editorially, or delete them.
